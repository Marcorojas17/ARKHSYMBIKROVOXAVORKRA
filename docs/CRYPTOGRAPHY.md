# ARKH Cryptography

## Algoritmos Utilizados
- **KDF:** Argon2id (64MB, 3 iteraciones).
- **Cifrado Simétrico:** AES-256-GCM.
- **Firma Digital:** ML-DSA-65 (Post-Cuántico) + ECDSA (Clásico).
- **Hash:** SHA-256 y SHA3-512.

## Estándares
- NIST FIPS 203 (ML-KEM)
- NIST FIPS 204 (ML-DSA)
- NIST FIPS 205 (SLH-DSA)
