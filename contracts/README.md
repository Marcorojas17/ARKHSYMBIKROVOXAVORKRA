# ARKH Smart Contracts

Este directorio contiene los contratos inteligentes que anclan los datos del ecosistema ARKH a la red de Ethereum/Polygon.

- `anchor.sol`: Contrato para registrar hashes SHA-256 y CIDs de IPFS.
- `anchor_pqc.sol`: Contrato experimental con firmas Post-Cuánticas.

## Despliegue
Usa Remix IDE o Hardhat para desplegar en la testnet de Sepolia.
