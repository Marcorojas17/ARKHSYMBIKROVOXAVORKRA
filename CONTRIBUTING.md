# Contribución a ARKHE-ZERO

Gracias por tu interés en contribuir.

## Estado Actual: Código Cerrado a Contribuciones Públicas
Actualmente, este repositorio es un proyecto de desarrollo privado y **no estamos aceptando Pull Requests públicos**. 

Esto se debe a que el núcleo del protocolo (criptografía post-cuántica y gestión de identidad) está en proceso de auditoría y patente.

## ¿Cómo puedes contribuir?
1. **Reportando errores:** Si encuentras un bug, por favor abre un Issue detallado.
2. **Sugerencias:** Puedes abrir un Issue con la etiqueta `enhancement`.
3. **Alianzas Enterprise:** Si eres una empresa interesada en integrar ARKHE-ZERO, contacta a marco.a.rojas.v@hotmail.com.

Por favor, lee nuestro `SECURITY.md` antes de reportar problemas sensibles.
