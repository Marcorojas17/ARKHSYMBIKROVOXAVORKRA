# Contributing to ARKHSYMBIKROVOXAVORKRA

## Process
1. Fork the repo and create your branch from `main`.
2. If you've added code, ensure tests pass (`npm test`).
3. Ensure your commits are signed with GPG.
4. Issue a Pull Request.

## Code Style
We use Prettier and ESLint. Please run `npx prettier --write .` before committing.
